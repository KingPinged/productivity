Session Intention Feature — Design Overview

Two components: input popup on Start, and persistent top-of-screen bar

1. Intention Input Popup (on Start click)

Intention Popup — appears when user clicks Start
What's your intention?
Stay focused. No side quests.
  • Modal dialog — blocks interaction until dismissed
  • Enter key submits, Escape skips
  • Skip starts the session with no intention text
  • Text stored in app state for the duration of the session

2. Top-of-Screen Intention Bar (during active session)

Intention Bar — always on top, horizontally centered
🎯 Finish the login page redesign
(rest of screen — bar floats above everything)
  • Frameless, always-on-top window — centered at top of screen
  • Hover → fully transparent (opacity 0); mouse out → fades back
  • Visible during WORKING, BREAK, and PAUSED states
  • Disappears when session ends (IDLE)
